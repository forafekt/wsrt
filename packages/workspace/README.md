# @wsrt/workspace

> [!WARNING]
> This package is part of WSRT, which is under active early development. APIs, configuration, behavior, and package boundaries may change without notice. It is not currently recommended for production or critical workloads.

Vite-independent workspace discovery, package graph resolution, aliases, and
non-destructive TypeScript/manifest projections. Resolution is always in memory;
`syncWorkspace` is the explicit persistence boundary.
